# DataAnalysis/data/

分析に使うデータを管理するフォルダ。

## 主担当
**3人目**

## フォルダ構成

| フォルダ | 内容 |
|---------|------|
| `samples/` | テスト・開発用のサンプルデータ |

## ルール
- `samples/` 内のサンプルデータのみ Git にコミットする
- Unity から実際に取得した本番データはコミットしない（`.gitignore` に追加）
- サンプルデータは現実的な値にする（アルゴリズムのテストに使うため）

## サンプルデータの形式例

```json
[
  {
    "carId": "car_001",
    "spaceId": "A-01",
    "eventType": "park",
    "timestamp": "2025-01-01T09:00:00",
    "position": { "x": 5.0, "y": 0, "z": 3.0 }
  }
]
```
