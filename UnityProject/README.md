# UnityProject/

駐車場シミュレーターの Unity プロジェクト本体。

## 主担当
| 担当 | 役割 |
|------|------|
| 1人目 | 駐車場シーンの構築・3Dレイアウト |
| 2人目 | 車・NPC の動作スクリプト |
| 4人目 | 全体統合・シーン結合・API通信 |

## このフォルダに含まれるもの
- `Assets/` — シーン・スクリプト・モデルなど全アセット（Git管理対象）
- `Packages/` — Unity パッケージ設定（Git管理対象）
- `ProjectSettings/` — プロジェクト設定（Git管理対象）
- `Library/` — Unity自動生成キャッシュ（**Gitに入れない**）

## Unity で開く方法
Unity Hub → Add → このフォルダ（`UnityProject/`）を選択する。
