# Assets/Materials/

マテリアル（`.mat`）とテクスチャ（`.png`, `.jpg`）を管理するフォルダ。

## 主担当
**1人目**（駐車場系）・**2人目**（車系）

## フォルダ構成例
```
Materials/
├── Cars/         ← 車のマテリアル（2人目）
├── ParkingLot/   ← 駐車場のマテリアル（1人目）
└── Textures/     ← テクスチャ画像
```

## 作り方
Project ウィンドウで右クリック → `Create → Material`

## 注意
- テクスチャ（PNG 等）は Git LFS で管理される
- 同じマテリアルを複数のモデルで使い回す（重複作成しない）
