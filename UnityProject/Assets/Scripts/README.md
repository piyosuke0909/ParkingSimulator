# Assets/Scripts/

C# スクリプトを役割別に管理するフォルダ。

## サブフォルダと主担当

| フォルダ | 主担当 | 内容 |
|---------|--------|------|
| `Vehicle/` | **2人目** | 車の移動・物理・NPC制御 |
| `Parking/` | **1人目・4人目** | 駐車スペースの状態管理 |
| `Network/` | **4人目** | Unity → API へのデータ送信 |
| `UI/` | **4人目** | 画面表示・HUD など |

## スクリプトの作り方
Unity Editor でフォルダを右クリック → `Create → C# Script`  
**ファイルを作ったら `.meta` ファイルも一緒にコミットすること。**
