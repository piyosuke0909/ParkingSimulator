# Assets/Scenes/

Unity のシーンファイル（`.unity`）を管理するフォルダ。

## 主担当とシーンの対応

| シーンファイル | 主担当 | 内容 |
|--------------|--------|------|
| `ParkingLot.unity` | **1人目** | 駐車場の3D空間・スペース配置 |
| `Vehicles.unity` | **2人目** | 車・NPC のテスト・動作確認用 |
| `Main.unity` | **4人目** | 全シーンを統合した本番シーン |

## ルール
- 自分が担当するシーン**以外は触らない**
- 変更前は Discord / Slack で一声かける
- シーンファイルは複数人が同時編集するとマージが壊れる

## シーンの作り方
Unity Editor の Project ウィンドウでこのフォルダを右クリック →  
`Create → Scene`
