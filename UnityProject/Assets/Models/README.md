# Assets/Models/

3D モデルファイル（`.fbx`, `.obj` など）を管理するフォルダ。

## サブフォルダと主担当

| フォルダ | 主担当 | 内容 |
|---------|--------|------|
| `Cars/` | **2人目** | 車の3Dモデル |
| `ParkingLot/` | **1人目** | 駐車場の建物・床・構造物 |
| `Environment/` | **1人目** | 地面・空・周辺環境 |

## Git LFS について
`.fbx` などの大容量ファイルは Git LFS で管理している。  
通常通り `git add` すれば自動的に LFS に送られる。

## 注意
- テクスチャはモデルと同じフォルダに置かず `Materials/` に分ける
- ファイルを追加したら `.meta` ファイルも一緒にコミットする
- テクスチャ解像度は 2048×2048 以下を推奨
