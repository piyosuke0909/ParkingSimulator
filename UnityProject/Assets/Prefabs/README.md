# Assets/Prefabs/

再利用可能なゲームオブジェクト（Prefab）を管理するフォルダ。

## サブフォルダと主担当

| フォルダ | 主担当 | 内容 |
|---------|--------|------|
| `Cars/` | **2人目** | 車・NPC の Prefab |
| `Parking/` | **1人目** | 駐車スペース・区画の Prefab |

## Prefab とは
一度設定したオブジェクトをテンプレートとして保存したもの。  
シーンに何度でも配置でき、Prefab を変更すると全配置済みオブジェクトに反映される。

## 作り方
Hierarchy（シーン上）のオブジェクトを Project ウィンドウのこのフォルダへドラッグ＆ドロップ。
