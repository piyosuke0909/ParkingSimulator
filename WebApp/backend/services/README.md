# WebApp/backend/services/

ビジネスロジック（経路計算・データ処理）を管理するフォルダ。  
API エンドポイント（routers）から呼び出される処理を分離して書く。

## 主担当
**3人目**

## 想定するファイル

| ファイル名 | 内容 |
|-----------|------|
| `route_optimizer.py` | 最適経路の計算ロジック |
| `parking_service.py` | 駐車状況の集計・管理 |

## 最適経路の考え方

駐車場のレイアウトをグラフとして扱う：
- **ノード**：交差点・駐車スペース入口
- **エッジ**：通路（距離をコストとする）

```
入口 → 通路A → 通路B → 空きスペース
       ↓コスト計算（Dijkstra / A*）
最短経路を座標リストで返す
```

1人目のシーン情報（スペース座標）をもとにグラフを構築する。  
座標マップは `DataAnalysis/` 側で生成して共有する。
