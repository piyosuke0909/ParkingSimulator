# WebApp/frontend/

React + TypeScript で作るフロントエンド。  
ブラウザ上で駐車場の状況をリアルタイムに表示する。

## 主担当
**3人目**

## フォルダ構成

| フォルダ | 内容 |
|---------|------|
| `src/components/` | 再利用可能な UI コンポーネント |
| `src/pages/` | ページ単位のコンポーネント |
| `src/hooks/` | データ取得などのカスタムフック |
| `src/types/` | TypeScript の型定義 |

## 主な画面

| 画面 | 内容 |
|------|------|
| 駐車場マップ | 全スペースの空き・使用中をリアルタイム表示 |
| 車の現在地 | 「自分の車はどこ？」を表示 |
| 誘導ルート | 最寄りの空きスペースへの経路を表示 |

## 起動
```powershell
npm install
npm run dev
# http://localhost:3000 で確認
```
