# frontend/src/components/

再利用可能な React コンポーネントを管理するフォルダ。  
複数のページで使い回せる部品をここに置く。

## 主担当
**3人目**

## 想定するコンポーネント

| ファイル名 | 内容 |
|-----------|------|
| `ParkingMap.tsx` | 駐車場マップ（スペースの空き状況を色で表示） |
| `CarStatus.tsx` | 車1台の状態（ID・停車スペース・時刻） |
| `RouteOverlay.tsx` | 最適経路を地図上に重ねて表示 |
| `SpaceIndicator.tsx` | 駐車スペース1区画の表示部品 |

## バックエンドとの接続
API 呼び出しはコンポーネント内に直接書かず、`../hooks/` にカスタムフックとして切り出す。
